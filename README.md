# 🌑 Obsidian Command Center

**The Ultimate Design System for Home Assistant.**

![Dashboard Preview](dashboard-preview.png)

Welcome to the official repository for the Obsidian Command Center. This is a high-density, glassmorphic UI designed for those who want their smart home dashboard in HA to feel like a pro-level OS.

## ✨ Key Highlights

- **Obsidian Command Center**: Deep blacks, custom typography, and SVG noise textures, optimized for main dashboards.
- **Obsidian Core Dark**: A dark core portal theme designed for your user profile settings, featuring high-contrast dark select inputs and dropdown menus.
- **Obsidian Portal**: A light slate core portal theme with deep navy text, optimized for those who prefer a premium light mode setting panel.
- **Glassmorphic UI**: High-density room cards with neon accenting.
- **Interactive Controls**: Custom vacuum and media cards with CSS animations.
- **Complete Kit**: Includes Dashboard YAML, Themes, and Install Guide.

## 🚀 Quick Start

1. **Theme**: Copy [themes/obsidian.yaml](themes/obsidian.yaml), [themes/obsidian_core_dark.yaml](themes/obsidian_core_dark.yaml), and [themes/obsidian_portal.yaml](themes/obsidian_portal.yaml) to your `/config/themes/` folder.
2. **Dashboard**: Use [dashboard/lovelace_dashboard_template.yaml](dashboard/lovelace_dashboard_template.yaml) as a template for your Lovelace UI.
3. **Guide**: Follow the [Step-by-Step Install Guide](INSTALL_GUIDE.md) for full setup instructions.

## 🛠️ Required HACS Integrations

Ensure you have these installed:

- `button-card`
- `mushroom`
- `mini-media-player`
- `layout-card`
- `card-mod`
